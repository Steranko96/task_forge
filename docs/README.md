# Documentation

- `TICKETS.md`: ticket status for both tracks.
- `PROGRESS.md`: observed evidence and completion records.
- `architecture/`: future architecture/scope decisions from requested tickets.
- `operations/`: future setup, deployment, rollback, monitoring, and recovery docs.
- `reference/`: immutable original inputs and conversion/change provenance.

Architecture and operations directories are placeholders. Do not treat them
as completed design or runbook deliverables. Implement documentation only as
part of an explicitly requested ticket.
